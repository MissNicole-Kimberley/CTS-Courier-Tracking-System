CTS – Courier Tracking and Management System

Project Overview
CTS is an academic project focused on simplifying courier operations
through parcel tracking, shipment management, and delivery monitoring. The system aims 
to improve operational efficiency, enhance parcel visibility, and support the 
effective management of courier services.

Objectives
- To simplify courier and shipment management.
- To support parcel tracking and delivery monitoring.
- To improve the organisation of courier operations.

Key Features
- Parcel tracking
- Shipment management
- Delivery monitoring

Technologies Used
- Python
